## yabai

This fork is a personal patch of [yabai](https://github.com/koekeishiya/yabai). Commits will be rebased on top of the upstream branch.

### Installation

Follow [upstream instructions for installing from HEAD](https://github.com/asmvik/yabai/wiki/Installing-yabai-(from-HEAD))
but tap and use `wxwern/formulae/yabai` for installation instead.
